Repositorio para el ejercicio práctico del Reto 5 de Desarrollo Ágil y Colaborativo.
# Práctica Git y GitHub UVEG Este repositorio fue creado como parte del ejercicio práctico de la materia Desarrollo Ágil y Colaborativo. En este ejercicio se utilizarán comandos básicos de Git para clonar un repositorio, descargar cambios, modificar archivos, guardar cambios, subirlos al repositorio remoto, crear ramas y unificar cambios.

## Cambios en rama pruebas Este cambio fue realizado desde la rama pruebas para mostrar el manejo de ramas en Git.
